# FAE 智能工作台

面向 Windows 本机、单用户和个人钉钉身份的技术支持工作台项目，目标是集中查看技术支持单、查询型号资料和责任人候选、起草回复并由用户确认后提交。

当前提供可双击启动的 Windows 安装包、本机后台、三栏工作台和可选的 Codex Skill。首次使用依次配置个人 AI 接口、扫码授权钉钉、保存可用的本机产品资料文件夹。三步完成后，左栏按优先级展示技术支持单，中栏提供表单字段、沟通记录和回复草稿，右栏展示手册、研发人员和可结合单据回答的 AI 助手。

## 安装 / 更新 / 卸载

- **安装**。将 `fae-workbench-skill-0.8.3.zip` 解压到任意文件夹，双击“启动 FAE 工作台.cmd”。安装包已包含构建好的网页和 PDF 文字提取运行文件，运行需要 Node.js 24 或更新版本。[下载 Node.js](https://nodejs.org/zh-cn/download)
- **更新**。双击“退出 FAE 工作台.cmd”或点击网页中的“退出工作台”，再替换解压后的工作台文件夹。配置和运行数据保存在单独的数据目录，默认为 `%LOCALAPPDATA%\FAE-Workbench`。
- **卸载**。先退出工作台，再删除解压后的文件夹。如需同时清除配置和运行数据，再删除 `%LOCALAPPDATA%\FAE-Workbench` 或 `FAE_DATA_DIR` 指定的目录。

启动器会复用已运行的后台，通过默认浏览器打开本机网页。页面建立会话并成功请求连接状态后，启动器才报告打开成功。如果 30 秒内未确认加载，后台会继续运行，可以再次双击打开。双击入口用中文提示结果，并在失败时等待按键。缺少钉钉命令行时仍可打开设置页，页面提供安装提示。

希望从 Codex 打开时，可把压缩包解压到 `%USERPROFILE%\.agents\skills\fae-workbench`，然后说“打开 FAE 工作台”。也可以在解压后的文件夹中手动调用同一个启动器。

```powershell
node .\scripts\launch.mjs
node .\scripts\launch.mjs --stop
```

命令行默认输出一行 JSON，双击入口使用 `--interactive` 输出中文提示。设置 `FAE_NO_BROWSER=1` 时跳过打开浏览器，JSON 额外包含供自动化使用的一次性本机启动地址。

## 开发与运行

在仓库根目录使用 Node.js 24 或更新版本：

```powershell
npm ci
npm run check
npm run dev
```

`npm run dev` 先构建 React 网页到 `dist/web`，再通过 `scripts/dev.ts` 启动 Node 本机后台并打开默认浏览器。后台只监听 `127.0.0.1` 的随机端口，直接托管网页；没有单独的 Vite 开发服务器。后台 TypeScript 由 Node 原生类型剥离运行。

`npm run build` 仅构建网页。运行依赖是固定版本的 React、React DOM 和 PDF.js（`pdfjs-dist`）。开发依赖是固定版本的 TypeScript、Prettier、Vite、React 插件及 Node/React 类型定义。

`npm run package` 先构建网页，再在 `dist/package/fae-workbench/` 组装运行文件，使用 Windows 自带的 `tar.exe` 生成 `dist/fae-workbench-skill-0.8.3.zip`。版本号取自 `package.json`。包内包含双击入口、`SKILL.md`、程序源码、构建好的网页，以及 PDF.js 文字提取所需的模块、字体、字符映射和许可证。解压后的目录可直接使用 Node 启动。

开发命令固定使用 `.runtime/app` 作为数据目录。通过启动器或模块接口启动时，数据目录优先使用 `FAE_DATA_DIR`，默认 `%LOCALAPPDATA%\FAE-Workbench`。该目录保存钉钉账号选择、资料目录、AI 接口地址和模型名称。AI API Key 由 Windows DPAPI 使用当前用户身份加密后单独保存。

自动化运行可先设置 `$env:FAE_NO_BROWSER='1'`，再运行 `npm run dev`。后台将输出一行 `{ "port": 数字, "launchUrl": "本机启动地址" }`，不自动打开浏览器。启动地址中的 code 只使用一次，成功后换成 HttpOnly、SameSite=Strict 会话 cookie，名称包含本实例端口。页面提示“会话已失效：请重新打开工作台”时，重新运行开发命令即可获取新的启动地址。

再次启动时，只有带密钥的健康检查通过、且进程号和端口都与锁文件一致，才复用既有服务。健康检查连接失败、超时或不匹配时自动清理残留锁并新建实例，不会终止锁文件中记录的其他程序。

设置向导先配置 OpenAI 兼容接口。填写接口地址和 API Key 后，点击“获取模型”，从下拉框选择。列表只有一个模型时自动选中，当前模型仍在列表中时优先选用。成功获取的列表最多保存 500 个模型名及获取时间，供工作台重启后继续使用。更换接口地址或 Key 后需要重新获取列表。获取失败、接口不支持列出模型或列表超过 500 项时，可手动填写模型名称，完成一次最小对话测试后保存。测试只发送固定内容。首次保存后进入钉钉授权步骤。

接口地址通常使用 HTTPS。本机和规定的内网地址允许 HTTP，页面会提示该地址不加密。保存后网页显示 Key 的末四位。修改地址时，只能在协议、主机和端口规范化后均相同的情况下沿用已保存的 Key。任一项改变时需要重新填写 Key。工作台顶部可随时重新打开设置。

设置页的“登录钉钉”和“重新登录”只启动固定的 `dws auth login`，用户本人在授权页扫码。同一时间只允许运行一个登录进程，五分钟超时。钉钉就绪后后台立即预读单据和详情。第三步建议 Windows 实际文档位置下的“FAE 工作台手册”。可用“选择文件夹…”打开 Windows 文件夹选择器，选好的路径由用户确认保存。目录必须是可读写的本机文件夹，可为已存在的上一级目录创建末级。扫描深度和条目数有限，文件夹失效后会回到第三步并保留原路径供修复。

资料目录轮询只确认目录存在、类型和实际位置。保存、后台首次检查、目录恢复或点击“刷新状态”时会核对写入能力，并安排一次有界 PDF 统计。例行统计最多每 10 分钟在后台运行一次，接口继续返回上次已知数量。手册写入发现权限或磁盘空间问题时，页面会回到资料设置。

点击“退出工作台”会关闭本服务和它启动的子进程。只有已登录且有多个账号时才显示账号选择；标签使用 CLI 返回的组织名称，缺少名称时使用组织 ID 的末六位。这些账号信息只用于本机页面。账号选择必须来自 CLI 返回的账号列表。API 校验会话、Host、Origin，所有 POST 还校验 `X-FAE-Request: 1`；会话失效与权限不足返回不同的原因类别，账号或资料目录等输入错误返回 400。

钉钉就绪后，后台自动读取列表，只保留“快速技术支持流程”和“客服技术支持流程”，合并重复单据并保留来源。CLI 要求待处理查询必须传时间范围，因此读取最近 365 天。抄送和我已处理读取最近 30 天，每个来源最多 5 页。“我已处理”只查询进行中的流程。列表分页读完立即发布内存快照，再以并发 3 预读全部详情和参与人姓名，先读未结束单据，再读已结束单据。未结束单据每轮重读，已结束单据在状态未变且完整缓存未超过 30 分钟时复用详情。身份核验缓存 10 分钟，登录、切换账号或连接状态变化时，与单据缓存一起作废。

后台正常每 5 分钟刷新一次，有最近 10 分钟内的网页访问时继续刷新，恢复访问时补读。单据来源或详情暂时读取失败时按 30 秒、1 分钟、2 分钟、5 分钟退避重试。暂时失败的详情先在本轮其他单据读完后补读一次。一次只运行一轮，手动刷新可提前安排。`GET /api/tickets` 立即返回当前快照，包含更新时间、计划刷新时间及预读进度。网页每 10 秒轮询快照，左栏按计划时间逐秒显示倒计时。受保护的 `POST /api/tickets/refresh` 立即返回。详情缓存命中时直接返回，仅能读取最近列表中的单据。

列表刷新整体失败时保留当前账号的上次列表、更新时间与详情。部分来源失败时保留该来源的上次条目，使用成功来源本轮读到的更新。左栏用一行小字汇总已读详情与失败数量，并标出列表来源是否读全。单据详情暂时读不到时可从中栏立即重试，需用户处理的钉钉连接问题继续醒目显示。

左栏按“待我处理、移交给我、未回复、已回复、我移交给别人、已结束”分组，已结束默认折叠。左栏卡片显示发起人和模板简称，详情读到后显示产品型号。中栏使用“发起人 · 模板名”作为标题，缺失发起人时显示模板名。工作台结合“确认收到问题”“问题解决方案及策略确认”节点和评论记录判断跟进进度。

“移交给我”包含已核实转交给本人、仍待本人处理或本人已经处理的进行中单据。工作台在当前运行期间持续跟进到流程结束。该组条目显示当前进度，按“待确认收到、未回复、已回复、待他人通过”排序。“已回复”组中的“待他人通过”排在该组最后。其余组内条目以及同一进度的条目越早发起越靠前，缺失发起时间排最后。

“我移交给别人”显示我在本轮转交且当前没有本人进行中任务的单据。“移交给我”和已结束单据优先进入各自分组。转交后有他人评论或执行审批动作时标为“对方已处理”，否则显示“暂无新动态”。当前处理人可核实时显示姓名。中栏状态为“已转交给他人”，可以照常评论。

首次预读时，左栏标明“读取中”或“暂未读到”。已经读到详情的卡片在重读期间继续使用上次的分组、标签和型号。重读失败计入左栏失败数，由后台按退避节奏补读。列表确认结束或待处理来源变化时立即更新。三栏独立滚动，宽度小于 1280 像素时默认收起左栏，本次打开期间保留手动选择。宽度小于 900 像素时资料和 AI 助手移到详情下方。

中栏标题为“发起人 · 模板名”，下方用标签显示审批编号、发起时间、等待时长和当前进度。可以从可信处理记录推算时，标题卡片显示当前步骤，左栏标注步骤简称和状态。遇到跳步、记录不完整或其他无法确认的情况，省略进度。可以审批时，标题卡片右侧显示决策区，并在可推算时提示同意后进入的步骤。有审批编号时点击即可复制。中栏按原顺序显示有内容的业务字段，跳过流程说明。多行文本保留换行，附件字段显示文件名。沟通记录和表单共用中栏的滚动区域，切换单据后从顶部开始，点击“跳到最新”可定位最新记录。“我的回复”固定在中栏底部，输入框随内容增高。点击“保存草稿”后，后台校验会话并按单据将草稿保存在本机内存中，切回该单据可继续编辑。退出工作台会清空草稿。可尝试给列表中的单据提交评论；仅来自“我已处理”的单据只提供评论。审批按钮依据钉钉待处理来源和预读详情中恰好一个属于当前用户的进行中任务展示，包括处于“移交给我”组的单据。“同意”的意见可留空，“客服技术支持流程”的拒绝需要填写意见。

同意和拒绝的确认框显示单据最近读取时间，可先点击“更新”。确认码绑定预读任务，只用一次，2 分钟过期。确认后使用预读任务发送一次。身份复用不超过十分钟的已核验缓存，过期时重新核验身份。命令明确成功后只更新本单。命令未明确成功时回读本单一次核实结果，流程变化时保留草稿，结果不明时提示到钉钉核对。同一单据再次操作前，必须先核实上次未生效才会发送。

“提交评论”直接发送，沟通记录立即显示本机的发送状态。成功后在真实记录读到时换成钉钉评论，明确失败时恢复原文，结果不明时保留条目供核对。本机条目保存在当前网页内存。AI 助手只可把回答放入本机草稿。中栏标题旁的“更新”只重读本单详情及相关姓名，已有同单读取时复用，更新后同步展示分组和资料。

右栏顶部用单行摘要显示手册和研发人员。找到手册时可直接打开，同一单据的多个型号各自显示一行。展开后可以查看产品页、本机存储状态或编码表、研发人员详情。摘要默认收起，展开状态存为浏览器本地偏好。钉钉就绪后，后台使用当前账号查找名称以“软件源码编号管理表”开头的唯一文件，下载到运行数据目录内的独立临时目录，按 XLSX 解析后清理临时文件。产品固件为必需工作表，工装固件和工业物联移交存在时一并读取。编码表索引保存在内存中。资料区按选中单据的产品型号展示完全一致或近似匹配的研发人员及归档信息，支持手动更新编码表。权限不足、未找到文件或找到多个候选时会显示对应提示。

产品资料目录可用后，后台以并发 2 向亿佰特官网查询已读详情的手册，只发送通过校验的规范化型号。找到和未找到的结果在本机内存中缓存 24 小时。暂时不可用时缓存 5 分钟，资料区也可手动更新。编码表下载或解析暂时失败时按退避节奏重试，权限不足、文件缺失或多个候选时可手动更新。发生官网故障时仍可正常读取单据和研发人员资料。

未结束且状态为“待确认收到”或“未回复”的单据，在详情预读结束且产品资料保存后以并发 2 预下载手册，包括“移交给我”组中的单据。已结束单据的手册在首次打开时下载。短期下载失败按相同的退避节奏重试。下载、查看和打开文件夹使用已保存的产品资料目录，开发命令使用系统临时目录覆盖。运行数据目录中的索引按资料目录记录匹配、文件名、大小、SHA-256 和下载时间。切换目录时清空旧的文件记录，保留型号匹配和旧目录文件。文件仍在且大小一致时直接使用，重启后也可沿用。保存时共用同名同内容的文件，对同名不同内容使用新文件名。“打开用户手册”在新标签页查看本机 PDF，“重新下载”保留旧文件，“打开手册文件夹”打开系统资源管理器。

AI 助手支持 Enter 发送和 Shift+Enter 换行，输入法拼字时 Enter 保持选字行为。首次提问可点击常用问题填入输入框。问题发送后，后台向设置中的 AI 接口发送当前单据的已投影文字、研发人员候选、相关手册段落和同单据问答。请求正文不含钉钉账号标识和句柄、AI Key、工作台程序、运行数据和产品资料目录的路径或图片附件的原始数据。手册按页在本机提取文字，按实际 SHA-256 缓存，用关键词匹配相关段落。缺少手册或文字层时可继续提问。每张单据可同时进行一条后台回答，切换单据、刷新页面或断开浏览器连接后仍继续。左栏标出正在回答的单据，回到原单据可通过轮询看到已有文字。点击“停止”、退出工作台、切换或退出钉钉账号会终止回答。页码引用可打开本机手册。回答展示加粗与纯文本，复制和放入回复时移除格式及页码标记。“放入我的回复”会把回答追加到现有草稿并保存。AI 记录按账号使用 Windows 当前用户加密保存在本机，每张单据保留最近 10 轮，重启后可继续使用。当前账号的列表完整读取后，后台清理已离开列表至少 30 天的记录。超出容量时优先清理最久未用的记录。可在右栏清空本单 AI 记录。

问答请求的输出长度使用服务商默认上限，程序保留 16 MiB 上游响应保护和 50,000 字正文展示范围。请求材料与历史合计仍按 32,000 字预算处理。上游连续 60 秒没有思考或正文增量时才判定超时，空白 SSE 行和保活注释不影响计时。网页可显示思考阶段和耗时，思考文字不离开后台流解析。带正文的截断答复仍写入历史。模型以正常结束或长度截断停止且未给出正文时，网页显示提示，本轮不保存。单张单据的加密历史支持最近 10 轮各 50,000 字正文。

可在 AI 助手标题栏选用已保存列表中的模型，切换立即保存，从所有单据的下一次提问起生效，顶部连接状态同步更新。下拉框里的“刷新列表”会使用已保存的接口地址和 Key。生成回答时暂不可切换，回答下方会记录当时使用的模型，重启后也可查看。没有可用列表时，可从标题栏进入连接设置修改模型。列表超过 500 项时，仍显示已配置的当前模型，可在连接设置中手动验证其他模型。

AI 助手占据右栏资料下方的空间，消息独立滚动，输入框随文字增长到约八行。点击“放大”可缩起左栏并扩大 AI 区，宽窗口仍可并排滚动查看单据，窄窗口用 AI 占用中栏和右栏。点击“收起”或按 Esc 恢复，Esc 优先关闭已经打开的确认框或图片查看层。放大状态存为浏览器本地偏好。

沟通记录按时间从早到晚显示。评论显示姓名、时间和纯文本内容，本人显示“我”。评论和系统动作的意见中，符合 `[名字](纯数字)` 格式的提及在后台转换为 `@名字`，数字标识随之去除。图片编号在当前账号的运行期间固定。图片接口只允许当前列表中当前详情仍包含的图片。后台匿名取得允许的钉钉 HTTPS 图片，在内存中校验类型和大小，按原始地址最多缓存 200 MB，并以并发 2 预取未结束单据的图片。网页最多保留 300 张已加载图片，切换单据后可复用缩略图和大图。切换账号会清空两层缓存，图片和地址均不写盘。评论、系统动作和发起时间按本机时区显示，今天省略日期、今年省略年份，缺失或无效时间显示占位符。系统动作优先显示钉钉返回的动作名称。空附件容器不显示也不计数，有名称的容器并入可确定的前一条记录。

详情预读会收集缺少姓名的参与人，通过唯一获准的 `contact user get --ids` 只读命令分批查询，每批最多 20 人；只保留人员标识与姓名，其他通讯录字段立即丢弃。姓名缓存只在内存中，登录、切换账号和身份失效时清空；查询失败保留成员标识末四位，不影响单据读取完整性。

单据读取缓存和回复草稿只存在本机内存中。AI 记录加密保存在本机运行目录。业务内容不写日志。表单内容按纯文本显示，不将网址转成链接。沟通记录中的附件保留名称，暂不支持的复杂字段给出提示。身份核验信息不会返回网页，账号选择使用本实例的不透明标识。

## 代码结构

- `packages/core`：共用连接与单据快照类型、单据分组与进度规则、错误分类、数据目录、原子配置读写、自有进程管理和 npm 安装目录候选。
- `packages/dingtalk`：钉钉命令白名单、连接状态、独立登录、身份缓存、编号表的定向搜索与下载、三个来源的单据列表与详情读取、独立写回白名单、任务交叉核验与详情写入核实、转入与转出核实、回复状态与流程进度推算、沟通记录投影、私有图片映射与有界读取、批量姓名查询及开发探针。
- `packages/ai`：OpenAI 兼容接口的地址验证、按来源复用 Key、配置与 DPAPI 密钥存储、模型列表获取与持久化、当前模型切换、思考事件与按输出续期的问答流。
- `packages/codetable`：编号表 XLSX 读取、型号索引、近似匹配与研发人员归档汇总。
- `packages/manuals`：官网型号查询、有界下载、本机索引、独立线程 PDF 文字提取和关键词检索。
- `apps/server`：回环 HTTP 服务、单实例锁、会话访问控制、连接与资料目录校验、Windows 文件夹选择器、单据预读与单张更新、记录图片门禁与预取缓存、编码表、手册、可恢复的后台 AI 对话与本机加密记录、回复草稿、预读确认与写回结果核实、静态网页托管。
- `apps/web`：React 首次设置向导、统一样式变量与响应式卡片布局、单据与沟通记录、审批编号复制、记录图片查看与内存缓存、回复编辑、钉钉写回确认、手册和研发人员摘要、AI 模型切换与放大模式，使用 Vite 构建。
- `skill/fae-workbench`：双击启动与退出入口、可选 Codex Skill 和共用启动器。
- `scripts`：开发后台入口、Windows 压缩包组装及钉钉开发探针。

钉钉探针使用本机已安装的钉钉 CLI 及其已有登录。多身份时必须通过 `--profile` 或环境变量 `FAE_DWS_PROFILE` 指定，命令行参数优先；身份可使用完整 profile 或能唯一匹配账号的组织 ID，并与认证状态交叉核对。探针不读取凭据文件。

`DWS_BIN` 可指定钉钉 CLI 的绝对可执行路径。未设置时查找 npm 全局安装包中的原生程序或 `bin/dws.js`。

所有钉钉调用由 `packages/dingtalk` 承接。通用执行器保持只读命令白名单，钉钉登录和审批写回分别使用独立的固定命令入口。探针仅查询审批或进行有界事件订阅，不提交审批、评论或消息。终端仅显示脱敏摘要，探针原始输出保存在被 Git 忽略的 `.runtime/`，连接模块运行数据保存在所选数据目录。`.runtime/` 以仓库根目录定位，与探针启动目录无关。

## 验证命令

| 命令                                                                | 参数与行为                                                                                                                | 退出码与输出                                                                                                                        |
| ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `npm run check`                                                     | 检查 Prettier 格式，然后运行 TypeScript strict 类型检查                                                                   | 0 通过；非 0 失败；结果输出到终端                                                                                                   |
| `npm run format`                                                    | 使用 Prettier 格式化工程文件，遵循 `.gitignore` 的忽略规则                                                                | 0 成功；非 0 失败；会修改文件                                                                                                       |
| `npm run typecheck`                                                 | 单独运行 `tsc -p .`，不生成编译文件                                                                                       | 0 通过；非 0 失败                                                                                                                   |
| `npm run --silent probe:dingtalk -- [参数]`                         | `--days 30`、`--page-size 20`、`--max-pages 5`、`--sample 1`、`--profile <身份>`；数值为默认值，sample 为每类模板的抽样数 | 0 全部读取成功；2 部分成功或分页未读完；1 参数错误、认证缺失、身份不明或全部失败；原始返回在 `.runtime/dingtalk-probe/<runId>/`     |
| `npm run --silent probe:event -- [--seconds 60] [--profile <身份>]` | seconds 默认 60，从 ready 起计时                                                                                          | 0 连接正常退出且订阅清理验证通过（没有事件也为 0）；1 未 ready、异常退出或清理未验证；原始返回在 `.runtime/dingtalk-event/<runId>/` |

`--silent` 消除 npm 自身的命令提示，使钉钉探针 stdout 只保留一个脱敏 JSON。错误摘要仅输出允许的错误类型，无法分类的错误使用 `unknown`。

探针的 `--days` 对待处理列表换算为毫秒 `--start/--end`。抄送列表使用 `--create-time-from/--create-time-to`，帮助未约定时区，按本机时区日期查询，边界精度为整天。只读摘要中的当前用户任务参与标记仅统计 `RUNNING` 任务。

事件只订阅任务创建、任务完成、任务转交、抄送四类；正常停止使用 duration 或关闭 stdin，超过 duration 加 30 秒仍未退出才强制终止并在摘要标记。身份识别、事件目录或订阅状态失败时摘要包含 `errorType`；订阅清理只有通过状态回读确认后才标记成功。
